# Python-Desde-Cero

¡Bienvenido/a! Este repositorio es un espacio donde comparto explicaciones sobre conceptos fundamentales de Python y los primeros pasos en el mundo de la programación.

Aquí comparto explicaciones sencillas, ejemplos y conceptos que ayudan a entender cómo funciona la programación, desde mi propia perspectiva como estudiante de Ingeniería Informática.

La idea es acercar la programación a quienes están comenzando, explicar las bases de forma clara y demostrar que no es necesario saberlo todo para empezar a programar.

## ¿Cuál es el propósito?

Compartir conocimientos sobre programación, explicar conceptos de manera clara y ayudar a quienes están comenzando a familiarizarse con Python.

Este repositorio no busca ser un curso ni una guía estructurada, sino una colección de explicaciones que permitan comprender mejor distintos conceptos de programación.

## ¿Qué encontrarás aquí?

- Conceptos fundamentales de Python.
- Explicaciones sobre elementos del lenguaje.
- Ejemplos de código.
- Ideas y conocimientos útiles para comenzar a programar.

## ¿Por qué Python?

Python es un lenguaje de programación conocido por su sintaxis legible y sencilla, lo que lo convierte en una buena opción para quienes quieren dar sus primeros pasos en la programación.

## Sobre este proyecto

Este repositorio nace de mi interés por la programación y de las ganas de compartir lo que voy aprendiendo como estudiante de Ingeniería Informática.

Creo que comprender los conceptos es tan importante como aprender a escribir código, y que compartir conocimientos también es una forma de seguir aprendiendo.
### Formato del material

Las explicaciones estarán disponibles en archivos **Jupyter Notebook (`.ipynb`)**, un formato que permite combinar texto, código Python y sus resultados dentro de un mismo documento.
#### ¿Cómo funcionan los notebooks?

Cada notebook está compuesto por celdas que pueden contener distintos tipos de contenido:

- **Celdas de texto:** permiten explicar conceptos, agregar ejemplos y escribir notas en formato Markdown.
- **Celdas de código:** contienen instrucciones de Python que puedes ejecutar para ver cómo funcionan.
- **Resultados:** al ejecutar una celda de código, puedes visualizar su salida directamente debajo de ella.

#### ¿Cómo puedes visualizar el material?

Puedes explorar los notebooks de distintas maneras:

1. **Desde GitHub:** abre cualquier archivo `.ipynb` directamente en el repositorio para leer las explicaciones y ver los ejemplos de código.
2. **Con Google Colab:** puedes abrir el notebook en [Google Colab](https://colab.research.google.com/) para ejecutar y modificar el código desde tu navegador, sin necesidad de instalar Python en tu computador.
3. **Con Jupyter Notebook:** si tienes Python y Jupyter instalados, puedes descargar el archivo y ejecutarlo localmente.
